This directory contains the reproducible code companion and starter configuration for the ZeroLabs technical brief: **"How to Create a GitHub Repo and Scaffold a Web Project"**.

## Quick Start

### 1. Prerequisites
- Docker & Docker Compose
- Python 3.11+
- Node.js 20+ (if frontend component included)

### 2. Setup Environment
```bash
cp .env.example .env
# Edit .env with your environment variables
```

### 3. Run Starter
```bash
docker compose up -d
# or run standalone python script
python3 starter.py
```
