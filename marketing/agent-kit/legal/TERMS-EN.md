## 2. What you are buying

Agent Kit is downloadable source code, deployment files and documentation for a
self-hosted task workspace operated by one technical operator. The current kit
contains the application, background worker, PostgreSQL deployment, bounded AI
tools, local MCP bridge, backup tooling and recovery documentation described on
the product page. The order must identify the version and exact deliverables.

You supply and administer the host and third-party accounts. AI tasks use the
OpenAI Responses API with a compatible model and are billed separately by that
provider. The kit price does not include hosting, model calls, domain registration,
offsite storage or custom implementation unless your order expressly includes
them. Its assistant cannot execute shell commands, browse the web, send messages,
access arbitrary files or deploy software. AI-generated output requires review;
the product does not promise that every output is correct.

Current baseline requirements are Ubuntu 22.04/24.04 or Debian 12, Docker Engine
and Compose 2.24.4+, Python 3, Bash, flock, two CPU cores, at least 2 GiB RAM
(4 GiB recommended), and 10 GiB free storage plus backups/build space. Setup
requires internet access and builds images locally. Initial release validation
must state the architecture tested; upstream amd64/arm64 support is not itself
evidence of a tested deployment on every host. Read the versioned requirements
before ordering. Product descriptions and express commitments form part of the
sale; these terms do not erase them or applicable statutory conformity rights.
